# C3 Bimetric Geometry & Dark Matter Simulations

This repository contains the Python source code used for the phenomenological simulations in the theoretical manuscript regarding tachyon condensation, the C3 geometry, and the Beta state.

* **mexican_hat.py** : Models the spontaneous symmetry breaking and the emergence of negative pressure (Dark Energy).
* **n_body_graviton.py** : N-body simulation demonstrating the tensor-Hermitian coupling (Graviton-Bridge) between baryonic and dark matter.
* **monte_carlo_beta_jump.py** : Stochastic simulation of the Beta Jump topological transition, modelling the Fermi-LAT galactic gamma-ray excess.
